# PDF資料整理アプリ

PDF・JPEG・PNGをブラウザ内でまとめ、管理表紙を先頭に追加して新しいPDFとして保存する静的Webアプリです。

## 主な機能

- PDF / JPEG / PNG の複数読込
- PDFと画像の混在
- ドラッグ操作で資料の順番を並べ替え
- JPEG/PNGはA4ページに自動配置
- 管理表紙を1ページ目に追加
- 管理項目
  - 年度
  - 学年
  - 科目
  - テスト名
  - 学期
  - 解答あり／なし
- 各プルダウンの
  - 追加
  - 編集
  - 削除
  - ドラッグ並べ替え
- 設定はブラウザの localStorage に保存
- 設定JSONの書き出し / 読み込み
- 元PDF・元画像は変更しない
- PDF/画像はサーバーへ送信せず、ブラウザ内で処理

## 使い方

1. `index.html` をブラウザで開く
2. PDF/JPEG/PNGを追加
3. 必要に応じてファイル順をドラッグで変更
4. 年度・学年・科目・テスト名・学期・解答を選択
5. 「PDFを作成して保存」を押す

## GitHub Pagesで公開する場合

このフォルダの中身をGitHubリポジトリへアップロードし、GitHub Pagesを有効にしてください。

※ PDF処理ライブラリ `pdf-lib` は jsDelivr CDN から読み込んでいるため、初回利用時を含めインターネット接続が必要です。

## 注意

- パスワード保護されたPDFは処理できません。
- 非常に大きなPDFや大量の高解像度JPEGを一度に扱うと、ブラウザのメモリを多く使用します。
- プルダウン設定は「そのブラウザ・その端末」に保存されます。別PCでも同じ設定を使う場合は「設定を書き出す」→「設定を読み込む」を使用してください。
- JPEG画像の向きは、スキャナーが保存した画像自体の向きをそのまま利用します。
