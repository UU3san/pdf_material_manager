# PDF資料整理アプリ v3

PDF・JPEG・PNGをブラウザ内でまとめ、向きを修正し、管理表紙を先頭に追加してPDFとして保存するWebアプリです。

## v3で追加した機能

- 管理番号（資料ID）をPDF作成時に自動発行
- 形式: `YYYYMMDD-連番`
  - 例: `20260903-001`
- 管理番号を
  - PDFの表紙
  - 保存ファイル名
  の両方へ記載
- 連番はその日ごとに001から開始
- 正常保存したときだけ連番を確定
- 次のPDFでは自動的に次番号を使用

> 連番はブラウザの localStorage に保存されます。同じPC・同じブラウザでの連続運用を前提にしています。複数PCで同時に使う場合は、将来データベース方式に変更すると完全な一意管理ができます。

## v2で追加した機能

- PDF/JPEG/PNGごとに
  - 左90°回転
  - 右90°回転
- 元資料を「開いて確認」
- PDFの場合は、そのPDF内の全ページをまとめて回転
- JPEG/PNGの場合は、画像自体を回転してA4 PDFへ配置
- 対応ブラウザでは「保存先フォルダ」を選択して直接保存
  - 例: `Y:\AIスキャン`
- フォルダ直接保存に対応しない場合は、通常のダウンロードへ自動フォールバック

## 既存機能

- PDF / JPEG / PNG の複数読込
- PDFと画像の混在
- ドラッグ操作で資料の順番を並べ替え
- JPEG/PNGはA4ページに自動配置
- 管理表紙を1ページ目に追加
- 管理項目
  - 年度
  - 学年
  - 科目
  - テスト名
  - 学期
  - 解答あり／なし
- 各プルダウンの追加・編集・削除・ドラッグ並べ替え
- 設定はブラウザの localStorage に保存
- 設定JSONの書き出し / 読み込み
- 元PDF・元画像は変更しない

## 保存先フォルダについて

`Y:\AIスキャン` のようなフォルダへ保存したい場合:

1. このアプリをGitHub Pagesで公開する
2. WindowsのEdgeまたはChromeで開く
3. 「保存先フォルダを選択」を押す
4. `Y:\AIスキャン` を選ぶ
5. 「PDFを作成して保存」を押す

ブラウザの安全仕様により、Webアプリ側が利用者の操作なしに `Y:\AIスキャン` を直接指定することはできません。

ブラウザが前回選んだ場所を開きやすくするため、フォルダ選択APIには固定IDを設定しています。

## おすすめ運用

- 原本JPEG/PDFは別フォルダに残す
- 資料の向きをこのアプリで修正
- 管理用ファイルはPDFに統一
- 管理PDFは `Y:\AIスキャン` 等へ保存
- 将来のMac mini / ローカルLLM導入時に、このPDF群をOCR・AI分類へ回す

## GitHub Pages

このフォルダの中身をGitHubリポジトリのルートにアップロードし、GitHub Pagesを有効にしてください。

※ `pdf-lib` はjsDelivr CDNから読み込むため、利用時はインターネット接続が必要です。

## 注意

- パスワード保護PDFは処理できません。
- 非常に大きなPDFや大量の高解像度画像を同時に処理するとブラウザのメモリを多く使用します。
- 保存先フォルダの直接指定はブラウザ対応状況に依存します。
- GitHub PagesはHTTPSなので、対応ブラウザではフォルダ選択APIを利用できます。
