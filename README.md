# PDF資料整理アプリ v9

PDF・JPEG・PNGをブラウザ内でまとめ、向きを修正し、管理表紙を先頭に追加してPDFとして保存するWebアプリです。

## v9で修正した機能

### 90° / 270°回転時に「用紙ごと」回転
以前はJPEG/PNGを左90°・右90°にすると、画像だけが回転し、PDF用紙は縦のままだったため画像が小さく見える場合がありました。

v9では、
- 0° / 180° → 用紙は縦
- 90° / 270° → **用紙そのものを横**
にします。

そのため、B4縦のスキャンを左90°にすると **B4横ページ** として保存され、画像もページいっぱいに近い大きさで表示されます。

### JPEG / PNGのPDF用紙サイズ
管理情報画面で選択できます。
- **B4（JIS）**：初期値・257 × 364 mm
- A4：210 × 297 mm

管理表紙もここで選んだ用紙サイズに合わせます。

※ 既存PDFを読み込んだ場合は、元PDFの用紙サイズをそのまま保持し、ページ回転情報で向きを変更します。

## v8で追加した機能

### 1. 保存済みPDFの再編集
- このアプリで作ったPDFをもう一度選ぶと、ファイル名から管理番号と管理情報を読み戻します。
- 同じ管理番号を引き継いで再保存できます。
- 以前の1ページ目は「旧管理表紙」として自動的に除外予定になります。
- サムネイルを見て、旧表紙を残したい場合は「このページを残す」で復活できます。
- 「新しい資料として扱う」を押すと、新しい管理番号で保存できます。
- v8以降で保存するPDFには管理番号と6項目をPDF内部の管理メタデータとして埋め込み、再編集時に優先して読み戻します。

### 2. サムネイルのチェック＋一括回転
- 各ページに「一括編集に選択」チェックを追加。
- 全ページ選択 / 選択解除。
- 選択ページを
  - 左90°
  - 右90°
  - 180°
  で一括回転できます。
- 個別ページの回転・除外も引き続き利用できます。

### 3. 混在資料の簡単登録
- 各管理項目に「— 未選択 —」を追加。
- 分かっている項目だけ選択できます。
- 「未選択を『混在』にする」を押すと、選択していない項目だけ一括で「混在」になります。
- 例: 学年=中3、科目=数学だけ選択 → 残り4項目を一括で「混在」。
- 未選択のまま保存することもでき、その項目はファイル名から省略され、表紙では「—」と表示されます。

## v7で追加した機能

- **文字の向きを自動判定**して 0° / 90° / 180° / 270° を補正
- **180°逆さまのページにも対応**
- PDFは**1ページごと**に向きを判定
- JPEG / PNGも自動判定
- 全ページの**小さいサムネイル一覧**を表示
- サムネイルごとに
  - 左90°
  - 右90°
  - ページ除外 / 復活
  を手動調整可能
- 自動判定した角度と判定信頼度を表示
- 白紙候補もサムネイル上で確認可能
- 文字が少なく自動判定できないページは「向き判定不可」と表示し、手動修正可能
- 「向きを再判定」ボタンを追加

### 文字方向判定について

Tesseract.js の Orientation and Script Detection (OSD) を使います。初回は判定用データを読み込むため少し時間がかかります。
GitHub Pages版ではインターネット接続が必要です。

文字がほとんどない図・写真だけのページは方向を判定できない場合があります。そのため、必ずサムネイルで最終確認できるようにしています。

## v6で追加した機能

- 白紙ページを自動削除（初期状態ON）
- PDF内の各ページを低解像度で解析し、ほぼ白紙のページを除外
- 単独のJPEG/PNGが白紙の場合も除外
- 白紙判定の強さを3段階で選択
  - 慎重（おすすめ）
  - 標準
  - 強め
- 保存完了時に「白紙○ページを削除」と表示
- 元PDF・元画像は一切変更しない

### 白紙判定について

初期設定は「慎重」です。薄い文字や小さな書き込みのあるページを残しやすくしています。
スキャナーの影や汚れのため白紙が残る場合だけ「標準」「強め」に変更してください。

白紙判定にはPDF.jsを利用します。GitHub Pagesで使う場合はインターネット接続が必要です。

## v5で追加した機能

- 「横向きのページを自動で縦向きにする」を追加（初期状態ON）
- JPEG/PNGは画像の縦横サイズを見て自動回転
- PDFはページごとに縦横を判定して自動回転
- 自動補正後も「左90°」「右90°」で手動調整可能
- 自動補正をOFFにして完全手動運用も可能

### 自動補正の限界

この自動補正はページ・画像の縦横サイズを基準にします。
そのため「ページサイズは縦長だが、スキャンされた文字だけが横倒し」のような画像内容までは判定しません。
その場合は手動回転で修正してください。

## v4で修正した点

- 「保存先フォルダを選択」ボタンが押せない問題を修正
- ボタンを常に押せるように変更
- 対応環境ではフォルダを直接選択
- 非対応環境では理由を画面に表示
- 「PDF作成時に保存場所を選ぶ」フォールバックを追加
- 最終手段として通常のブラウザダウンロードにも自動対応
- 現在のブラウザがフォルダ直接保存に対応しているか画面表示

### Y:\AIスキャンへ保存するおすすめ方法

1. GitHub Pages版をWindowsのMicrosoft EdgeまたはGoogle Chromeで開く
2. 「保存先フォルダを選択」を押す
3. `Y:\AIスキャン` を選ぶ
4. PDFを作成する

`showDirectoryPicker()` はHTTPSなどの安全なコンテキストでのみ利用でき、ブラウザによって対応状況が異なります。

## v3で追加した機能

- 管理番号（資料ID）をPDF作成時に自動発行
- 形式: `YYYYMMDD-連番`
  - 例: `20260903-001`
- 管理番号を
  - PDFの表紙
  - 保存ファイル名
  の両方へ記載
- 連番はその日ごとに001から開始
- 正常保存したときだけ連番を確定
- 次のPDFでは自動的に次番号を使用

> 連番はブラウザの localStorage に保存されます。同じPC・同じブラウザでの連続運用を前提にしています。複数PCで同時に使う場合は、将来データベース方式に変更すると完全な一意管理ができます。

## v2で追加した機能

- PDF/JPEG/PNGごとに
  - 左90°回転
  - 右90°回転
- 元資料を「開いて確認」
- PDFの場合は、そのPDF内の全ページをまとめて回転
- JPEG/PNGの場合は、画像自体を回転してA4 PDFへ配置
- 対応ブラウザでは「保存先フォルダ」を選択して直接保存
  - 例: `Y:\AIスキャン`
- フォルダ直接保存に対応しない場合は、通常のダウンロードへ自動フォールバック

## 既存機能

- PDF / JPEG / PNG の複数読込
- PDFと画像の混在
- ドラッグ操作で資料の順番を並べ替え
- JPEG/PNGはA4ページに自動配置
- 管理表紙を1ページ目に追加
- 管理項目
  - 年度
  - 学年
  - 科目
  - テスト名
  - 学期
  - 解答あり／なし
- 各プルダウンの追加・編集・削除・ドラッグ並べ替え
- 設定はブラウザの localStorage に保存
- 設定JSONの書き出し / 読み込み
- 元PDF・元画像は変更しない

## 保存先フォルダについて

`Y:\AIスキャン` のようなフォルダへ保存したい場合:

1. このアプリをGitHub Pagesで公開する
2. WindowsのEdgeまたはChromeで開く
3. 「保存先フォルダを選択」を押す
4. `Y:\AIスキャン` を選ぶ
5. 「PDFを作成して保存」を押す

ブラウザの安全仕様により、Webアプリ側が利用者の操作なしに `Y:\AIスキャン` を直接指定することはできません。

ブラウザが前回選んだ場所を開きやすくするため、フォルダ選択APIには固定IDを設定しています。

## おすすめ運用

- 原本JPEG/PDFは別フォルダに残す
- 資料の向きをこのアプリで修正
- 管理用ファイルはPDFに統一
- 管理PDFは `Y:\AIスキャン` 等へ保存
- 将来のMac mini / ローカルLLM導入時に、このPDF群をOCR・AI分類へ回す

## GitHub Pages

このフォルダの中身をGitHubリポジトリのルートにアップロードし、GitHub Pagesを有効にしてください。

※ `pdf-lib` はjsDelivr CDNから読み込むため、利用時はインターネット接続が必要です。

## 注意

- パスワード保護PDFは処理できません。
- 非常に大きなPDFや大量の高解像度画像を同時に処理するとブラウザのメモリを多く使用します。
- 保存先フォルダの直接指定はブラウザ対応状況に依存します。
- GitHub PagesはHTTPSなので、対応ブラウザではフォルダ選択APIを利用できます。
